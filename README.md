# Painel de Controle de Tempo

Dashboard visual em React para apresentar horas de atividades e comparações com a semana anterior.

## O que o projeto apresenta

- Cards de trabalho, jogos, estudo, exercício, social e autocuidado.
- Componentes reutilizáveis para apresentação das atividades.
- Dados de demonstração definidos em um módulo JavaScript.

## Tecnologias

React · JavaScript · CSS · React Icons · Create React App

## Executar localmente

```bash
git clone https://github.com/WeldonCarlos/Painel-de-controle-de-tempo.git
cd Painel-de-controle-de-tempo
npm install
npm start
```

Abra o endereço informado no terminal.

## Comandos disponíveis

| Comando | Uso |
| --- | --- |
| `npm start` | `react-scripts start` |
| `npm run build` | `react-scripts build` |
| `npm test` | `react-scripts test` |

Os scripts são os definidos em `package.json`; sua presença não indica que foram executados nesta revisão de documentação.
